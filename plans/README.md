# Plans Overview / Progress

This page gives an overview of the plans in this repository. Each plan lives in
`plans/` and is numbered with a zero-padded two-digit prefix in chronological
order. Statuses:

- `[x]` — decided / closed
- `[-]` — in progress / drafted
- `[ ]` — planned / not started
